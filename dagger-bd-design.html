一职业定位

匕首是以高频近战攻击积累【杀阶】，并在红阶选择继续维持红阶，或主动使红阶降为黄阶的输出武器。

三套BD共享节奏 杀意管理 → 完成BD升阶行为 → 进入红阶 → 刷新红阶或主动降为黄阶 → 再次完成升阶行为回到红阶
BD核心玩法红阶决策层级
毒刃刺维持【中毒】与【剧毒侵蚀】；主目标同时带有两种状态时，单体使用【十字斩】升阶，群体使用【病毒散播】传播中毒并升阶红阶下主目标同时带有【中毒】和【剧毒侵蚀】时，决定继续刷新红阶或使用【见血封喉】

爆刺常态施加并消费【基础致命爪痕】，大招内连续施加并消费【超越爪痕】主要在开启【暗影超越】前决定是否投入【影袭筹谋】和当前杀阶

4.4 红阶保红与见血封喉

见血封喉

点出精通节点【见血封喉】后，红阶下使用【十字斩】或【病毒散播】命中同时带有【中毒】和【剧毒侵蚀】的主目标时：

  • 刷新红阶12秒
  • 【十字斩】按钮临时显示为【见血封喉】
  • 【病毒散播】保持原按钮和剩余CD
  • 十字斩原CD继续在后台计算
项目规则
消耗25杀意【模拟值】
可用时间6秒【模拟值】
CD不读取十字斩当前CD；每次命中同时带有【中毒】和【剧毒侵蚀】的主目标，最多触发1次按钮替换
伤害造成红阶十字斩120%档基础伤害，并追加X终%攻击力物理伤害【待数值】
状态红→黄；目标身上的【中毒】与【剧毒侵蚀】保留，不刷新、不移除
追加伤害限制不触发毒发、二刀追击和其他命中追加效果，不递归
恢复按钮使用或机会到期后恢复十字斩，并继承十字斩后台剩余CD

玩家可以暂时保留【见血封喉】，继续使用【病毒散播】处理群体目标；使用或持续时间结束后，按钮恢复为【十字斩】。

4.5 随机事件｜毒发

毒发
  • 同时带有自身施加的【中毒】和【剧毒侵蚀】的目标，其任一状态的自然周期伤害生效时有12%概率触发；该效果具有8秒内置冷却。
  • 施毒高亮6秒，下一次施毒变为免费【毒发刺击】。
  • 【毒发刺击】对主目标追加X毒发%攻击力物理伤害，并使【病毒散播】剩余CD缩短4秒。
  • 致命涂毒期间概率提高到24%。
  • 毒发只提供额外收益，不是基础循环成立条件。

4.6 固定大招替换｜致命涂毒

致命涂毒

精通节点【致命毒液】将固定终极武器槽中的【影刃解放】替换为【致命涂毒】：

  • 持续8秒，CD45秒。
  • 释放时重置【病毒散播】CD。
  • 毒发概率12%→24%。
  • 持续期间，【十字斩】与【病毒散播】造成的物理伤害提高50%【模拟值】。
  • 持续期间，【十字斩】或【病毒散播】第一次命中同时带有【中毒】和【剧毒侵蚀】的主目标时，杀阶提升2阶。

单体：致命涂毒 → 建立【中毒】与【剧毒侵蚀】 → 十字斩提升杀阶并获得【凝毒追刺】和【穿刺毒核】 → 暗影刺击消费【凝毒追刺】 → 毒性感染消费【穿刺毒核】 → 再次用十字斩提升杀阶 → 红阶选择继续刷新或使用见血封喉

4.8 单体／群体

单体
凝毒穿刺
【十字斩】命中同时带有【中毒】和【剧毒侵蚀】的主目标时，为其施加持续6秒的【穿刺毒核】；下一次【毒性感染】消费标记，追加X穿刺%攻击力物理伤害，并使新的【剧毒侵蚀】持续时间增加4秒。
群体
毒雾蔓延
【病毒散播】命中同时带有【中毒】和【剧毒侵蚀】的主目标时，将持续12秒的【中毒】传播给最多4名次要目标，并为这些目标施加持续3秒的【蔓延毒核】。标记结束时，对目标及其3米内最多5名敌人造成X蔓延%攻击力物理伤害。
两者分别强化【十字斩】的单体后续攻击和【病毒散播】的群体传播。

随机事件｜幻影终结

幻影终结 【黑色幻影】命中时25%概率触发，ICD8秒，储存8秒。

结算优先级：
1. 如果目标拥有自身施加的【基础致命爪痕】或【超越爪痕】，【十字斩】／【致命影啸】保持正常效果并消费标记；【幻影终结】不消耗。
2. 只有当前目标没有可消费标记时，【十字斩】／【致命影啸】才显示幻影高亮，并可释放一次免费直接伤害形态。
3. 免费直接伤害形态不消耗杀意，不消费爪痕，不升阶，不生成筹谋，也不会使红阶降为黄阶。
4. 免费直接伤害形态不能绕过原技能CD；技能在CD时只显示储存提示，不显示为可立即释放。
5. 释放其中一个技能的免费直接伤害形态后消耗【幻影终结】；另一个技能恢复正常。

这样，同一个按钮不会在玩家准备处决时突然变成不消费标记的攻击。
